28 — Multiplayer Card Game

Designed and built a real-time multiplayer platform for "28" (Twenty-Eight), an Indian trick-taking card game popular in Kerala, played by 4 players in fixed partnerships. I personally built the game engine, service architecture, and database schema, then directed AI coding agents to complete implementation across a 35,000+ line, three-service production codebase.

  • Real-time game engine in Node.js (Express + Socket.IO) driving the full two-round bidding phase, trump selection, and trick-play logic over WebSockets, synchronizing live 4-player sessions.
  • Python (FastAPI + SQLAlchemy/Alembic) REST API for auth, accounts, and scoring, and a cross-platform Flutter client (Riverpod + Freezed) shipping to Android, iOS, web, and desktop — both sharing one PostgreSQL database and JWT auth.
  • Rule-based AI bots that autonomously bid, select trump, and play tricks, plus production hardening: transaction-wrapped game mutations, bidding-phase/card-ownership gates, and bcrypt password hashing.
  • Deployed and hosted on Hetzner Cloud (systemd services) behind Cloudflare, with a custom deploy script automating git sync, dependency installs, DB migrations, service restarts, and Flutter web builds.

Cricket Stats & Live Scoring

Designed and built a full-stack cricket data and live-scoring platform covering 19 IPL seasons, 800+ players, live match scores, and fan voting. I personally designed the PostgreSQL schema, data pipelines, and core ranking algorithm, then directed AI coding agents to complete implementation across a 16,000+ line codebase spanning data pipelines, API, and frontend.

  • Three data pipelines normalizing 19 seasons of squads and stats into PostgreSQL, with cross-source player name resolution, and a Python/FastAPI REST API (~20 endpoints) with Firebase auth (Google + phone OTP) gating a one-vote-per-user ballot system.
  • Live-scoring provider integration with Redis caching, a responsive HTML/JS/Tailwind frontend with leaderboards and live match modals, deployed via Docker (Postgres, Redis, FastAPI, nginx) and validated with load tests.
